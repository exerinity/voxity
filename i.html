Install Voxity as a PWA

Voxity will work fine in your browser as normal, but for the best experience, you should install it. Here is how:

  • Chrome / Chrome Canary / Brave / Helium
  • Vivaldi
  • Firefox

Chrome / Chrome Canary / Brave / Helium

  1. Click on the 3-dotted menu in the omnibox:

  2. Go to "Cast, save and share" / "Save and share" then press "Install page as app..."


  3. Name the app whatever you want, then press Install.


Vivaldi

  1. Right-click on the tab, go to "Progressive Web Apps" then click "Install page as app..."

  2. Name the app whatever you want, then press Install.


Firefox

PWAs are a bit different in Firefox, but...

  1. Press "Add tab to taskbar" in the omnibox
